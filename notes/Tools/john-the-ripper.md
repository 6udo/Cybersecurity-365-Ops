# Tool Mechanics: John the Ripper
When you steal passwords from a Linux server, you do not get plain text. You get a cryptographic hash—a scrambled string of characters generated by a one-way mathematical function (like SHA-256). You cannot mathematically "decrypt" a hash.

John the Ripper is an offline cracking tool. It works by taking a massive dictionary of known passwords [rockyou.txt], mathematically hashing every single word in that list, and comparing the result to your stolen hash. When the two hashes match, the password is cracked.

Before cracking Linux hashes, you must prepare the files. Linux stores usernames in [/etc/passwd] (readable by everyone) and the actual hashes in [/etc/shadow] (locked down to the root user). You must combine them so John knows which hash belongs to which user.

Command 1 (Prepare): unshadow passwd.txt shadow.txt > unshadowed.txt

Command 2 (Crack): john --wordlist=/usr/share/wordlists/rockyou.txt unshadowed.txt
